# 🍽️ Azeem's Restaurant

A simple and beginner-friendly **Restaurant Web Page** created using **HTML5**.

This project is built to practice semantic HTML, images, lists, tables, figures, captions, and basic webpage structure.

---

## 📌 Features

- 🍕 Today's Special section
- 🖼️ Food images with captions
- 📋 Restaurant menu
- 🍔 Main Course section
- 🥖 Starters section
- 🍰 Desserts section
- 💰 Price List table
- 💵 Prices displayed in Indian Rupees
- 📊 Table using `rowspan` and `colspan`
- 🧾 Table with `thead`, `tbody` and `tfoot`
- 🏷️ Semantic HTML5 structure

---

## 🧠 HTML Concepts Used

### Semantic Elements

```html
<header>
<main>
<section>
<footer>
```

These semantic elements are used to create a meaningful and well-structured webpage.

### Image and Figure Elements

```html
<figure>
<img>
<figcaption>
```

`<figure>` is used to group an image with its caption.

`<img>` is used to display images on the webpage.

`<figcaption>` is used to provide a caption for an image.

### List Elements

```html
<ul>
<li>
```

Nested unordered lists are used to organize the restaurant menu into different categories.

### Table Elements

```html
<table>
<thead>
<tbody>
<tfoot>
<tr>
<th>
<td>
```

The table is used to display the restaurant's price list in a structured format.

---

## 📊 Table Concepts Used

### rowspan

`rowspan` is used to combine multiple rows.

Example:

```html
<td rowspan="2">Pizza</td>
```

The **Pizza** category covers two rows in the table.

### colspan

`colspan` is used to combine multiple columns.

Example:

```html
<td colspan="2">Total Items</td>
```

The **Total Items** cell covers two columns.
